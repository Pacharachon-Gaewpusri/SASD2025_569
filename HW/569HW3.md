Utility Class: \n
System.Math: เกี่ยวกับการคำนวณทางคณิตศาสตร์ทั้งหมดใน class นี้ \n
System.IO.File: ข้างใน class มี static method สำหรับจัดการไฟล์ \n
System.Linq.Enumerable: มี static extension methods ขยาย method LINQ \n
System.Convert:ใช้เปลี่ยน data format \n
System.Environment: ใช้ตั้ง environment \n

Mutable Class: \n
System.Collections.Generic.List<T>: แก้ไขหลังจากประกาศตัวแปรได้ \n
System.Text.StringBuilder: ไม่ใช่ string แต่เป็นตัวอักษรแยกกันที่เรียงกันอยู่ จึงแก้ไขหลังจากประกาศ class ได้ \n
System.Net.Http.HttpClient: เปลี่ยน ค่า BaseAddress หรือ Timeout หลังสร้าง class ได้ \n
System.Data.DataTable: เก็บ table ในลักษณะที่n row และ column แก้ไขแยกกันได้ \n
System.Xml.XmlDocument: เก็บไฟล์ xml ในรูปแบบที่แก้ไข nodes ได้ง่าย \n
System.Environment: แก้ไข environmentได้\n

Immutable Class: \n
System.String: The most famous immutable class. Every time you "change" a string, .NET creates a new one in memory. \n
System.DateTime: (Technically a struct, but behaves as an immutable object). You cannot change a DateTime instance; you call .AddDays() and it returns a new DateTime. \n
System.Collections.Immutable Namespace: This contains classes like ImmutableList<T>, ImmutableDictionary<T>, and ImmutableArray<T>. \n
System.Uri: Once a URI is created, you cannot change its parts (host, path, query); you must create a new Uri object. \n
System.Version: Represents a version number (Major.Minor.Build.Revision) which is fixed upon instantiation.\n
