Utility Class: 


- System.Math: เกี่ยวกับการคำนวณทางคณิตศาสตร์ทั้งหมดใน class นี้ 

- System.IO.File: ข้างใน class มี static method สำหรับจัดการไฟล์ 

- System.Linq.Enumerable: มี static extension methods ขยาย method LINQ 

- System.Convert:ใช้เปลี่ยน data format 

- System.Environment: ใช้ตั้ง environment 



Mutable Class: 


- System.Collections.Generic.List<T>: แก้ไขหลังจากประกาศตัวแปรได้ 

- System.Text.StringBuilder: ไม่ใช่ string แต่เป็นตัวอักษรแยกกันที่เรียงกันอยู่ จึงแก้ไขหลังจากประกาศ class ได้ 

- System.Net.Http.HttpClient: เปลี่ยน ค่า BaseAddress หรือ Timeout หลังสร้าง class ได้ 

- System.Data.DataTable: เก็บ table ในลักษณะที่n row และ column แก้ไขแยกกันได้ 

- System.Xml.XmlDocument: เก็บไฟล์ xml ในรูปแบบที่แก้ไข nodes ได้ง่าย 

- System.Environment: แก้ไข environmentได้



Immutable Class: 


- System.String: สร้าง string ใหม่ แทนที่อันเก่าใน memory เมื่อมีการแก้ไข

- System.DateTime: (Technically a struct, but behaves as an immutable object) เปลี่ยนไม่ได้ แต่จะสร้างวันที่ใหม่ได้ด้วยฟังก์ชั่น .AddDays() ที่จะ return ค่าอันใหม่แทน

- System.Collections.Immutable Namespace: รวม class ต่อไปนี้ ImmutableList<T>, ImmutableDictionary<T>, and ImmutableArray<T>

- System.Uri: URI แก้ไขไม่ได้ สร้างใหม่อย่างเดียว

- System.Version: คนนอกแก้ไม่ได้
